# SmartVA Data Model V1

## Purpose

Defines the core TypeScript objects used throughout the SmartVA runtime.

These types are UI-independent.

---

# Cause

Represents a SmartVA cause of death.

Fields:

- id
- name

Example:

Stroke
Tuberculosis
Pneumonia

---

# Symptom

Represents a SmartVA symptom variable.

Fields:

- code
- description

Example:

s105
s23991
s88884

---

# InterviewRecord

Represents questionnaire responses.

Fields:

- id
- module
- answers

Modules:

- adult
- child
- neonate

---

# SymptomVector

Represents generated symptoms.

Structure:

code -> boolean

Example:

s105 = true
s109 = false

---

# CauseScore

Fields:

- causeId
- score

Generated by tariff scoring.

---

# CauseRank

Fields:

- causeId
- score
- rank

Generated by rank processing.

---

# PredictionResult

Fields:

- primaryCause
- likelihood
- topThreeCauses
- ruleTriggered
- keySymptom

---

# RedistributionResult

Fields:

- causeId
- weight

Used for undetermined causes.

---
