# SmartVA Core Interfaces V1

## Cause

Represents a cause of death.

Fields:

- id: number
- name: string

Example:

44 -> Stroke

---

## Symptom

Represents a SmartVA symptom.

Fields:

- code: string
- description: string

Examples:

s105
s23991
s88884

---

## InterviewRecord

Fields:

- id: string
- module: adult | child | neonate
- answers: Record<string, unknown>

---

## SymptomVector

Fields:

Record<string, boolean>

Example:

s105 = true
s109 = false

---

## CauseScore

Fields:

- causeId: number
- score: number

Generated by tariff engine.

---

## CauseRank

Fields:

- causeId: number
- score: number
- rank: number

Generated by ranking engine.

---

## PredictionResult

Fields:

- primaryCause
- likelihood
- topThreeCauses
- ruleTriggered
- keySymptom

---

## RedistributionResult

Fields:

- causeId
- weight

Used when a case is undetermined.

---

## ModuleType

Values:

- adult
- child
- neonate
